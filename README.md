## ℹ️ À propos du projet

Ce portfolio a été conçu dans le cadre d'un atelier pratique sur les bases du développement web HTML5 et CSS3. Il permet de regrouper et d'exposer mes différents projets, ma progression d'apprentissage ainsi que mon CV en ligne.

---

## ✨ Fonctionnalités

- **Navigation fluide :** Barre de navigation fixe avec ancres internes (`#home`, `#about`, `#work`, `#resume`, `#contact`).
- **Présentation (About) :** Informations personnelles, localisation et profil d'apprentissage.
- **Galerie de projets (Work) :** 
  - Workshop HTML (balises sémantiques, tableaux, formulaires).
  - Page Menu Restaurant (*Wonder Food*).
  - Démo multimédia avec éléments audio et vidéo HTML5 natifs.
- **CV & Compétences (Resume) :** 
  - Tableau des compétences techniques (HTML5, CSS3, JavaScript).
  - Parcours de formation ordonné (GoMyCode).
- **Formulaire de contact :** Formulaire sémantique avec validation des champs requis (nom, email, sujet, message).

---

## 🛠️ Technologies utilisées

- **HTML5 :** Balisage sémantique, formulaires, tableaux, éléments audio/vidéo.
- **CSS3 :** Stylisation, mise en page et typographie avec [Google Fonts (Roboto)](https://fonts.google.com/specimen/Roboto).

## 🚀 Lancer le projet

1. **Cloner ou télécharger le dépôt :**
   ```bash
   git clone https://github.com/samihakallel0206/portfolioHtml.git
   ```

2. **Ouvrir le fichier principal :**
   Double-cliquez sur `index.html` ou ouvrez-le dans le navigateur de votre choix (Chrome, Firefox, Edge, etc.).

3. **Avec Live Server (VS Code) :**
   - Faites un clic droit sur `index.html` dans VS Code.
   - Sélectionnez **Open with Live Server**.
